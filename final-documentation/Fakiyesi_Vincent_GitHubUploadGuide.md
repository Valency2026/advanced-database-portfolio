# How to put this portfolio on GitHub (no software to install)

The assessor needs a **private** GitHub repository with **progressive commits**. You can do
all of this in the browser.

## 1. Create the account and repository (5 minutes)

1. Go to https://github.com and sign up (use your Miva email or any email).
2. Click the **+** at the top right → **New repository**.
3. Repository name: `advanced-database-portfolio`
4. Visibility: **Private**.
5. Tick **Add a README file**, then **Create repository**.

## 2. Upload the work in stages (this is what creates the "progressive" history)

Do **not** upload everything in one go. Upload one portfolio folder at a time, ideally on
different days, with a short commit message each time:

| Upload | What to drag in | Commit message to type |
|---|---|---|
| 1 | `README.md` (replace the auto one) and `portfolio-1-database-design/` | `Portfolio 1: case study, ER diagram, schema, constraint tests, normalisation` |
| 2 | `portfolio-2-query-optimisation/` | `Portfolio 2: queries, execution plans before/after indexing, analysis` |
| 3 | `portfolio-3-transactions-concurrency/` | `Portfolio 3: transfer procedures, transaction and concurrency demos` |
| 4 | `portfolio-4-nosql/` | `Portfolio 4: MongoDB document model, pymongo demo, JSONB demo` |
| 5 | `portfolio-5-distributed-cloud/` | `Portfolio 5: streaming replication, failover, partitioning, cloud report` |
| 6 | `final-documentation/` and `Fakiyesi_Vincent_README.txt` | `Final documentation: summary, reflection, AI-use declaration, references` |

For each upload: open the repository → **Add file** → **Upload files** → drag the whole
folder from your computer onto the page (folders upload with their structure) → type the
commit message → **Commit changes**.

## 3. The repository link

The repository is `https://github.com/Valency2026/advanced-database-portfolio`. This link
is already in `README.md`, `Fakiyesi_Vincent_README.txt` and the summary document.

## 4. Give the assessor access

Private repositories are invisible to others until you share them. Repository →
**Settings** → **Collaborators** → **Add people** → enter the assessor's GitHub username
or email (ask on the course forum which one to use). The brief says the repository must be
accessible **before** you submit the form.

## 5. Submit the form

- Zip the folder `Fakiyesi_Vincent_2026-A-MIT-0304` (right-click → Compress / Send to zip).
- Upload the zip as "zipped folder" and `Fakiyesi_Vincent_README.txt` as "ReadME file".
- Submit the 2–3 page `Fakiyesi_Vincent_PortfolioSummary.pdf` through the LMS as well if
  the LMS has its own upload point.
